# 🍁 韩国首尔 & 釜山晚秋自由行漫游指南 (11.24 – 11.29)

> **2人晚秋赏枫 · 小众非标商业 · 美食与圣诞季探索**  
> 专为手机移动端浏览优化的类 App 单文件交互式旅行指南。

🔗 **在线预览 / Live Demo**: [https://zhaoxz.github.io/korea-autumn-guide/](https://zhaoxz.github.io/korea-autumn-guide/)

---

## ✨ 核心特色

1. **移动端优先布局 (App-like Mobile UI)**
   * 底部 5 大原生风格 Tab 栏（🗓 行程、🗺 地图、🍁 发现、🍜 美食、🧳 准备）。
   * 顶部日期横向滑动 Chip，支持手机左右滑动手势翻天（Swipeable Itinerary）。
   * 全屏视网膜高清自适应卡片。

2. **精选晚秋风光与非标商业**
   * 🍁 **晚秋金秋天幕**：首尔文庙 500 年参天古银杏金色穹顶、德寿宫石墙路金色地毯、昌德宫后苑秘苑晚枫水面倒影、梵鱼寺金井山红叶古刹。
   * 🛍️ **非标商业 & 潮流买手店**：圣水洞延武场街快闪、Point of View 策展式文具店、Haus Dosan 装置艺术、COEX 星空图书馆、益善洞暖灯韩屋街、田浦咖啡街。
   * 🎄 **浪漫夜景与圣诞彩蛋**：新世界百货本店外墙巨型圣诞灯光动画、蚕室乐天世界圣诞市集、海云台第 13 届灯光节开幕日、广安里大桥海面霓虹。
   * 🌊 **釜山海滨特色**：海云台 Blueline 天空胶囊海边彩色小火车、白浅滩海崖小镇、甘川文化村落日彩屋。

3. **双层交互式免 Key 地图 (Leaflet + OpenStreetMap)**
   * 每日行程地图：清晰标注当日路线连线、景点数字序号、推荐住宿区范围。
   * 全览大地图：支持城市切换（首尔/釜山）、标签筛选、一键飞向目标景点及 Naver / Kakao 地图联动搜索。
   * 完全开源免费、免 API Key、无水印。

4. **实用旅行工具箱**
   * 餐厅排队与 Catch Table 订位场景说明。
   * 实时进度交互式行李打包清单（自动持久化保存勾选状态至本地缓存）。
   * 首尔/釜山晚秋温差穿搭、即时免税退税规则、2 人详细预算估算表。
   * 两侧边距优雅飘落的红枫叶与黄色爱心环境动效（自动在距离底部 1/3 高度淡出）。

```bash
# 构建生成最终的 index.html
python3 build.py
```
